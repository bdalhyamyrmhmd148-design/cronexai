# CronexAI

A modern, responsive Persian (RTL) AI product landing page built with vanilla HTML, CSS, and JavaScript.

## Features

- Persian RTL layout and responsive navigation
- Dark premium visual style with violet/cyan gradients
- Responsive feature cards and product preview
- Interactive local demo form (no API calls)
- Accessible labels and reduced-motion support
- No build step or external dependencies

## Run locally

Open `index.html` in any modern browser.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment to finish. The published URL will appear in the Pages settings.

## AI integration note

The demo is frontend-only and produces a sample response locally. To connect a real AI model, create a backend/API endpoint and keep provider API keys on the server; never expose secret keys in browser JavaScript.
